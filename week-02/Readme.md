## Overview

Week 02 focuses on understanding how machine learning works, how learning approaches differ, how data and models are evaluated, and when machine learning is or is not a suitable solution.

## Learning Objectives

- Understand the relationship between AI, Machine Learning, Deep Learning, Generative AI, and LLMs.
- Learn about datasets, samples, features, labels, and data quality.
- Compare supervised, unsupervised, and reinforcement learning.
- Understand classification, regression, clustering, and other ML task types.
- Explain the difference between an algorithm, a model, training, and inference.
- Understand evaluation metrics, overfitting, underfitting, and generalisation.
- Identify common ML failure modes and the importance of human oversight.
- Evaluate when to use machine learning instead of a rule-based approach.
- Explore an ML application in DFT and semiconductor test engineering.

## Semiconductor Engineering Connection

This week's work explores how machine learning can support semiconductor engineering and DFT workflows.

The case study investigates ML-assisted prediction of potential test failures using historical test data and design characteristics. Possible features include scan-test coverage, test-pattern characteristics, and historical failure data. The target could be a test-pass or test-fail classification.

Model performance should be evaluated using suitable metrics such as precision, recall, and F1-score. Any illustrative results must be clearly labelled and must not be presented as experimentally verified findings.

Machine learning can help engineers prioritise investigation and identify suspicious patterns, but it should not replace established test procedures, diagnosis, or engineering sign-off.
