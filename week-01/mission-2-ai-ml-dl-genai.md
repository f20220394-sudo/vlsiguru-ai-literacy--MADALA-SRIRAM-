# Mission 2 — AI, ML, Deep Learning, and Generative AI

## Four short explanations

- **Artificial Intelligence (AI):** A broad field concerned with building systems that perform tasks associated with capabilities such as reasoning, perception, planning, or language understanding.
- **Machine Learning (ML):** An approach within AI in which a system learns patterns from data rather than relying only on manually specified rules.
- **Deep Learning (DL):** A part of ML that uses neural networks with multiple layers to learn representations and patterns.
- **Generative AI (GenAI):** AI systems that generate new content, such as text, images, audio, or code, based on patterns learned during training and the current input.

## Relationship diagram

```text
Artificial Intelligence (AI)
└── Machine Learning (ML)
    └── Deep Learning (DL)
        └── Many modern Generative AI systems
```

This is a useful simplified diagram, not a claim that all generative AI must use deep learning or that every deep-learning system is generative.

## Examples

| Concept | Example | Why it fits |
|---|---|---|
| AI | A planning system that selects actions to reach a goal | Performs a task associated with intelligent behaviour |
| ML | An email spam classifier trained on labeled examples | Learns patterns from examples |
| DL | A neural network with multiple layers used for image recognition | Uses a multilayer neural network |
| GenAI | An LLM drafting a short explanation from a prompt | Generates text |

## Explain the diagram

AI is the broadest category. ML is one way to build AI systems. Deep learning is one approach within ML. Many current generative systems use deep neural networks, including transformer-based language models. These categories overlap, so the diagram is a teaching aid rather than a complete taxonomy.
