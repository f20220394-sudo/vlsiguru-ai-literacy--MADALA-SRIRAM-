# Mission 2 – What Makes Deep Learning Different?

## 1. Relationship Between AI, ML and DL

**Artificial Intelligence (AI):** Making machines perform tasks that normally require human intelligence.

**Machine Learning (ML):** A part of AI where computers learn patterns from data.

**Deep Learning (DL):** A part of machine learning that uses neural networks with multiple layers.

**Neural Network:** A computational model containing interconnected units called neurons.

Relationship:

AI → Machine Learning → Deep Learning → Deep Neural Networks

## 2. Comparison

| Approach | How it works | Example | Limitation |
|---|---|---|---|
| Rule-based system | Uses predefined rules | Flag a test result when current exceeds a limit | Cannot easily handle complex patterns |
| Traditional ML | Learns from selected features | Classifying scan-test failures using failure counts | Depends on feature selection |
| Deep Learning | Learns patterns through multiple neural-network layers | Identifying defects in semiconductor images | Requires sufficient quality data and computing resources |

## 3. Why Are Neural Networks Interconnected?

Neurons receive information and process it using weights, biases and activation functions.

The connections allow information to move from one layer to another.

## 4. What Does Learning Mean?

Learning means identifying useful patterns from examples.

For example, a model may learn patterns associated with defective semiconductor inspection images.

## 5. Why Is Deep Learning Useful?

Deep learning is useful for complex inputs such as:

- Images
- Audio
- Text
- Complex signal patterns

## 6. Do More Layers Always Improve Accuracy?

No.

More layers can help learn complex patterns, but they can also increase training time and overfitting.

A complex network is not automatically better.

## 7. When Is Traditional ML Better?

Traditional ML or rule-based systems may be better when:

- The dataset is small.
- The problem is simple.
- The features are already known.
- The result must be easy to interpret.

## Example Outside Semiconductors

In banking, machine learning can help identify suspicious transactions using transaction information.

Deep learning may identify more complex patterns from large datasets.

## Conclusion

Deep learning is powerful for complex data, but the correct approach depends on the problem, data quality and available resources.
